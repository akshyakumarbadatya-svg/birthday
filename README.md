# 🎂 Happy Birthday! - Interactive Greeting Website

A personalized, interactive birthday greeting website built to celebrate a special day. Designed with smooth animations, responsive layouts, and custom interactive elements.

## ✨ Features
- **Interactive Countdown / Celebration Trigger:** Animated reveal for the birthday message.
- **Photo Gallery / Memory Lane:** Responsive grid showcasing favorite moments.
- **Custom Audio / Confetti Effects:** Built-in celebratory animations using JavaScript.
- **Responsive Design:** Fully optimized for both mobile and desktop screens.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure
- **CSS3:** Flexbox/Grid layouts, custom keyframe animations
- **JavaScript (ES6+):** DOM manipulation, event handling, and interactive effects
